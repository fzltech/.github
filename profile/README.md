# FZL

Hello. I'm Jeroen Fränzel, and I build software as FZL.

> Correctness-first software that runs on your own infrastructure.
> It tells you what it has proven, and what it hasn't.

Most software fails quietly. A model guesses, a parser drifts, a scanned field lands one digit off. I build software whose results are checked against something independent of them, so you can trust a result or see exactly where it breaks.

This is where the source lives.

**What I build**

- **Correctness-first.** Verification layers, mathematical cross-checks, and explicit confidence instead of hopeful output.
- **Local-first.** Runs on your infrastructure, with no mandatory cloud.
- **Applied maths and CS.** Vision, retrieval, and modelling work where the maths carries real weight.

**How I work**

Solo and hands-on. A few projects at a time, and the person you talk to writes the code. I'm open to a defined build or an ongoing role.
